# effectFusion

**Bayesian Effect Fusion for Categorical Predictors**

Variable selection and Bayesian effect fusion for categorical predictors in
linear and logistic regression models. Effect fusion answers the question
which categories have a similar effect on the response. The package fuses
those categories to obtain a sparser representation of the model.

Method described in [Pauger & Wagner, 2019](https://doi.org/10.1214/18-BA1096).

CRAN check failures were recorded on 2022-05-25, and the package was
subsequently archived

## Original authors

The original package is the work of Daniela Pauger, Magdalena Leitner, Helga
Wagner and Gertraud Malsiner-Walli, with contributions from Nicholas G. Polson,
James G. Scott, Jesse Windle and Bettina Grün.

Additionally contains code for Polya-Gamma data augmentation taken from the
`BayesLogit` package by Nick Polson, James Scott & Jesse Windle.
